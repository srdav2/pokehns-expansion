# How to Continue Your Save: Sovereign → Gilded

Your **Pokémon Sovereign Version** save carries over into **Pokémon Gilded Version**. The two games share one save format. You copy your save file next to the Gilded game and give it a matching name. It takes about two minutes.

> **Your Sovereign save is not used up.** You're copying it. Your original file stays where it is, and you can keep playing Hoenn with it.

---

## Before you start
- Finish the **Distortion Rift** in Sovereign (the post-game, after the Meteor Falls trial). When the **"THE RIFT IS OPEN"** screen appears, write down the **RIFT CODE**.
- The game saves itself at that screen. **Save states do not carry over**, so only the in-game save counts.
- Use the **same release number** of both games (for example, both v1.2). Mismatched versions refuse to load.

---

## The quick version (any emulator)
1. **Close the emulator completely** after the Rift screen, so the save file is written to disk.
2. **Find your Sovereign save.** It's usually in the same folder as the game, with the same name: `Pokemon Sovereign.gba` → `Pokemon Sovereign.sav`.
3. **Make a backup copy** somewhere safe.
4. **Copy** the save into the folder with your Gilded game.
5. **Rename the copy** so it matches the Gilded game's name exactly, apart from the extension: `Pokemon Gilded.gba` → `Pokemon Gilded.sav`.
6. Open Gilded and choose **CONTINUE**. Your new journey starts. Check the Rift Code matches the one you wrote down.

---

## Step-by-step by emulator

### mGBA (Mac, Windows, Linux)
- By default the save sits next to the game and has the same name with `.sav`.
- If you've set a custom save folder (**Settings → Paths → Saves**), look there instead.
- Copy it, rename it to match the Gilded game, then open Gilded and choose Continue.

### RetroArch (any platform)
- Saves are in RetroArch's **`saves`** folder, with the extension **`.srm`**: `Pokemon Sovereign.srm`.
- If **"Sort Saves into Folders by Core Name"** is turned on, look in a subfolder such as `saves/mGBA/`.
- Copy it, rename it to `Pokemon Gilded.srm`, and keep it in the same folder. Load Gilded with the **same core**.

### Delta (iPhone and iPad)
1. In your game library, long-press **Sovereign** and choose **Export Save File**. Save it to Files.
2. Long-press **Gilded** and choose **Import Save File**. Pick the file you just exported.
3. Open Gilded and choose Continue.
(Menu wording can differ between app versions.)

### Android (Pizza Boy GBA, My Boy!, Lemuroid and similar)
- The save is usually next to the game file, or in the app's own "saves" folder. Check the app's settings for the save location.
- Use a file manager app to copy it and rename it to match the Gilded game. Some apps have **Import/Export save** in their menu instead.

### Flash cartridges (EZ-Flash, EverDrive and similar)
- Saves are files on the SD card, usually in a **`SAVER`** or **`SAVES`** folder, named after the game.
- Copy it on your computer, rename it to match the Gilded game, and put it back on the card.
- If the cart asks for a save type, choose **FLASH 128K** (also shown as "1M Flash" or "128KB").

### Real physical cartridges
Not supported. Each cartridge has its own save chip.

## What carries over, and what doesn't
| Carries over | Stays behind in Hoenn (for now) |
| --- | --- |
| Your name, look, trainer ID | Your bag, money and badges |
| Your game settings (difficulty, Nuzlocke, randomizers, followers) | Your Hoenn party and PC. Sealed, **not lost**. They come back after Gilded's Johto Pokémon League. |
| Your Pokédex | |
| The 3 Pokémon you chose for Arceus. Arceus returns them early in Johto, at levels 5, 10 and 15. | |

## Troubleshooting
| You see | What to do |
| --- | --- |
| Gilded shows **NEW GAME** only | The save name doesn't match the game name, or it's in the wrong folder. Check the extension is `.sav` (or `.srm` in RetroArch), not `.sav.txt`. |
| "Complete the Distortion Rift in SOVEREIGN VERSION first" | You copied a save from before the Rift screen. Finish the Rift in Sovereign, close the emulator, and copy again. |
| "This save is from a different version" | Update both games to the same release. |
| "This journey continues in GILDED VERSION" (shown in Sovereign) | You opened your Gilded save in Sovereign. Use your original Sovereign save, or your backup. |
| Rift Code doesn't match | You copied an older save. Copy again right after the Rift screen. |
| The emulator says the save is corrupt | Set the save type to **Flash 128K**. In VBA-M: **Options → Emulator → Save Type**. Then try again with your backup. |

**Always keep a backup of your Sovereign save before copying.**
